# Appendices & Historical Content

This directory contains legacy documentation, historical decisions, deprecated proposals, and massive reference files that clutter the main navigation.

## Subfolders

### `2023-04-planning/`

- **What it contains**: 90+ timestamp-prefixed design and planning documents (`2023-04-23-*`, etc.).
- **Why it exists**: Preserves the original April 2026 architecture sprint documents for historical context without cluttering the active specs.
- **How to reference it**: "See appendices/2023-04-planning/ for initial spec concepts."

### `deprecated/`

- **What it contains**: Outdated release proposals and v1 integration plans.
- **Why it exists**: To keep a record of what was superseded.
- **How to reference it**: Review these to understand why we pivoted away from open-sourcing the Python codebase.

### `historical-decisions/`

- **What it contains**: V0.2/V0.3 architectural artifacts (formerly `ProbablyTrash/`).
- **Why it exists**: Retains early iteration designs.
- **How to reference it**: "See appendices/historical-decisions/ for V0.3 architecture discussions."
