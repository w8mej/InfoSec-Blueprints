# Start Here: SentinelMesh Reference Documentation

Welcome to the SentinelMesh reference documentation. This directory contains the architectural SentinelMesh, technical specifications, and operational guides for the autonomous incident response platform.

## What's in this folder?

This folder is organized into clear sections depending on your role and what you are trying to accomplish.

### 🏛️ For Architects (System Design & Decisions)

If you are looking to understand how SentinelMesh works under the hood or reviewing our architectural choices:

- Start with the [Core Concepts](core/README.md) folder.
- Read [ARCHITECTURE.md](core/ARCHITECTURE.md) for a high-level system overview.
- Review [DATA_SCHEMA.md](core/DATA_SCHEMA.md) to understand how data moves through the system.

### 🛠️ For Engineers (Technical Specs & Implementation)

If you are building integrations, modifying the core, or writing playbooks:

- Review the [Technical Specs](technical-specs/README.md) for deep dives into specific system components.
- Check the [Capabilities](capabilities/README.md) folder for implementation plans and tool expansions.
- Read [CORE_FEATURES.md](core/CORE_FEATURES.md) for a summary of the superpowers implemented.

### 🔎 For Investigators (Guides & Dashboards)

If you are operating the platform, reviewing incident responses, or utilizing the dashboards:

- Head to the [Guides](guides/README.md) folder.
- Read [DASHBOARDS.md](guides/DASHBOARDS.md) for an overview of the Sentinel Mesh UI.
- Review [EXAMPLES.md](guides/EXAMPLES.md) and [HITL_OPERATIONS.md](guides/HITL_OPERATIONS.md) to understand human-in-the-loop workflows.
- Check the [FAQ](guides/FAQ.md) for common questions.
