## Key Concepts

- **TIERs**: A progressive maturity model for agentic operations, from foundational signing (TIER 1) to autonomous execution (TIER 4).
- **capabilities**: Modular, agentic capabilities that enhance playbook precision and response speed.
- **Generators**: Tools like `SigmaNotebook` and `CacaoSidecar` that transform detection logic into actionable response playbooks.
